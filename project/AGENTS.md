# Roles

The SOP's nine roles, as they apply here. One agent may hold several; the review record says which
agent reviewed which revision and how independent it was (GR-5.2).

| Role | Does | Hands to |
|---|---|---|
| Architect | Owns `content/map.yml`, page types and routes | Author, diagrammer |
| External researcher | Turns research leads into a source register with primary sources and dates | Author, accuracy reviewer |
| Author | Writes pages to template from the source register | Diagrammer, reviewers |
| Diagrammer | Systems-view figures in `content/diagrams/`, checked at intended size and 390 px | Site builder |
| Site builder | Generator, styles, checks, workflows | Reviewers |
| Accuracy reviewer | Claims, formulas, sources, benchmarks (§2) | Author |
| Confidentiality reviewer | Fit for public use, attribution (§1) | Author |
| Editorial reviewer | Reads as a newcomer; labels, prose and map agree (§3, §4) | Author |
| Maintainer | Coordinates, keeps `STATUS.md`, prepares the final review package | Vishal |

The AI SDLC Map's `.claude/agents/` and skills are the reference prompts; port them when the first
content section starts, rewriting tool and subject references rather than renaming (SOP bootstrap).
