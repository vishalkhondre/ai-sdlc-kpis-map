About this demo

Sample data, not real benchmarks

Explore 49 metrics using fictional engineering teams. Names, definitions, formulas, interpretation and balancing measures come from Vishal Khondre’s AI SDLC Metrics & KPIs Map ↗, licensed under CC BY 4.0 ↗. Sample observations and dashboard groupings were created for this demo.

Three ways to start

The Enterprise, Customer and Employee lenses change the headline selection. A metric can serve more than one lens. The five dimensions in the sidebar follow the source map.

Reading a comparison

Team and adoption filters select the same fictional service groups in both windows. Adoption describes the group after rollout. A change between periods can have many explanations. Use a throughput measure alongside quality and developer experience.

Using the offline file

The charts, data and font are included. Use the external links for the original metric definitions and credits when you have an internet connection. Use Tab to navigate, Enter to open a metric and Escape to close a dialog.
